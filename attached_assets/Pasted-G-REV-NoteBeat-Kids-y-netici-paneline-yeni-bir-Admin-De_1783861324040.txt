GÖREV

NoteBeat Kids yönetici paneline yeni bir Admin Device Security sistemi ekle.

Mevcut kodları değiştirme.

Mevcut endpointleri bozma.

Mevcut authentication sistemini koru.

Yeni özellikler modüler şekilde eklensin.

Kod kalitesi yüksek olsun.

Typescript strict mode uyumlu olsun.

Render + Neon PostgreSQL uyumlu olsun.

React Query cache yapısını bozmasın.

Performans kaybı oluşturmasın.

AMAÇ

Admin paneline yalnızca yetkili cihazlardan giriş yapılabilsin.

Normal öğretmen ve öğrenci girişleri bundan etkilenmesin.

Bu sistem sadece ADMIN hesabı için çalışsın.

CİHAZ KAYIT SİSTEMİ

Her admin hesabı için maksimum:

• 1 Masaüstü / Laptop

• 1 Mobil Telefon

tanımlanabilsin.

İLK GİRİŞ

Admin hesabı ilk kez giriş yaptığında;

Eğer kayıtlı masaüstü cihaz yoksa,

o bilgisayar otomatik olarak yetkili masaüstü cihazı olarak kaydedilsin.

Aynı şekilde,

eğer kayıtlı telefon yoksa,

ilk giriş yapan telefon otomatik kaydedilsin.

Admin herhangi bir işlem yapmak zorunda kalmasın.

SONRAKİ GİRİŞLER

Admin tekrar giriş yaptığında;

cihaz bilgisi kayıtlı cihaz ile eşleşiyorsa

girişe izin ver.

YENİ CİHAZ

Eğer farklı bir bilgisayar

veya

farklı bir telefon

giriş yapmaya çalışırsa;

kesinlikle giriş yaptırma.

HTTP 403 döndür.

Ekranda şu mesaj gösterilsin:

"Bu cihaz admin paneli için yetkilendirilmemiştir."

CİHAZ TANIMA

Device Fingerprint kullan.

Fingerprint oluştururken;

Browser

Operating System

Platform

Language

Timezone

Screen Resolution

User Agent

bilgilerinden hash üret.

Fingerprint düz metin tutulmasın.

SHA-256 ile hashlensin.

BİLGİSAYARI DEĞİŞTİR

Admin butona bastığında;

mevcut bilgisayar kaydı silinsin.

Bir sonraki başarılı giriş yapan bilgisayar

otomatik olarak yeni yetkili bilgisayar olsun.

TELEFONU DEĞİŞTİR

Admin butona bastığında;

mevcut telefon kaydı silinsin.

Bir sonraki başarılı giriş yapan telefon

otomatik olarak yeni telefon olarak kaydedilsin.

ŞİFRE GÜVENLİĞİ

Admin hesabında;

5 başarısız giriş denemesinden sonra

hesabı 15 dakika kilitle.

Mesaj:

"Çok fazla hatalı giriş yapıldı. Lütfen 15 dakika sonra tekrar deneyiniz."

15 dakika sonunda

otomatik açılsın.

PERFORMANS

Bu sistem;

Render Starter üzerinde sorunsuz çalışmalı.

Neon PostgreSQL'de gereksiz sorgu üretmemeli.

N+1 query oluşmamalı.

React Query cache etkilenmemeli.

Mevcut authentication akışı bozulmamalı.

GÜVENLİK

JWT doğrulaması korunacak.

Yetkisiz cihaz hiçbir şekilde admin paneline erişemeyecek.

Öğretmen ve öğrenci girişleri bu sistemden etkilenmeyecek.

✓ İlk telefon otomatik kaydediliyor.

✓ Yeni telefon reddediliyor.

✓ "Telefonu Değiştir" çalışıyor.

✓ Render uyumluluğu korunuyor.

✓ Mevcut sistemde hiçbir özellik bozulmuyor.
