# NOTEBEAT KIDS – PRODUCTION SHIELD v1

## GÖREV TANIMI

Bu görev yeni özellik geliştirme görevi değildir.

Bu görev mevcut çalışan sistemi bozmadan Production güvenilirliğini ve gözlemlenebilirliğini artırma görevidir.

Kod yazmadan önce mevcut sistemi analiz et.

Hiçbir çalışan endpoint'i değiştirme.

Hiçbir authentication yapısını değiştirme.

Hiçbir Redis mimarisini değiştirme.

Hiçbir Socket.io mantığını değiştirme.

Hiçbir Leaderboard algoritmasını değiştirme.

Hiçbir puan hesaplama mantığını değiştirme.

Hiçbir öğrenci, öğretmen veya admin akışını değiştirme.

Amaç yalnızca sistemi izlenebilir, denetlenebilir ve veri kaybına karşı daha güvenli hale getirmektir.

## 2. ERROR CENTER

Yeni bir merkezi hata sistemi oluştur.

Amaç:

Sistemde oluşan bütün beklenmeyen hatalar tek yerde toplanmalıdır.

Yeni tablo gerekiyorsa oluştur.

Tutulacak bilgiler:

Tarih

Severity

Route

Institution

Teacher

Student

Admin

Error Message

Stack Trace

Request ID

Resolved

Sadece beklenmeyen sistem hataları kaydedilsin.

Normal kullanıcı hataları (401, yanlış şifre vb.) kaydedilmesin.
